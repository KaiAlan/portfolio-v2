# portfolio — project rules

Next.js **16.3.2** App Router · React **19.2.8** · Tailwind **v4** (PostCSS, no
config file) · Contentful · Cloudflare R2 for media · `motion` v13. Uses parallel
routes (`app/@modal`) for the lightbox.

`npm run dev | build | lint | setup:contentful | seed | seed:clean`

Read `docs/HANDOFF.md` first — it holds current state. `docs/PLAN.md` is the
spec (`CONTEXT.md` and `COSMOS-DESIGN.md` hold the reasoning); don't re-derive it.

**Before writing any animation, transition, easing or duration, read
`docs/MOTION.md`.** It is the motion equivalent of the token block in
`globals.css`, and it is binding: never invent a duration or a curve, use the
`--dur-*` / `--ease-*` tokens and the presets in `lib/motion.ts`. The sourced
research behind it is `docs/superpowers/research/2026-09-04-motion-design.md`.

- `AGENTS.md` is **generated by `next dev`** and re-adds itself. Commit it with
  your work instead of stripping it from the diff.
- This Next.js is newer than training data. Read `node_modules/next/dist/docs/`
  before writing App Router code.
- Never prefix a Contentful token with `NEXT_PUBLIC_`. Delivery is read-only and
  server-safe; management is write access.
- `NEXT_PUBLIC_CDN_URL` must be the custom R2 domain — `r2.dev` is rate-limited
  and unusable in production.
- Not deployed. No domain, CDN, or host configured yet.
